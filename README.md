# The World in One Picture — 20 Nov 2026

This repository is an entry to the [make.fun bounty](https://make.fun/bounty/news-image-20261120). The program copies a one-page newspaper image to the output directory. The image sums up the world news of Friday 20 November 2026, covering the ICJ Rohingya ruling, the Trump-Xi-Putin summit, the AI market sell-off and the Riyadh skyscraper strike.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
